АИС «ТЕХНОКОНТУР»

Шифр темы «Провидец» · ТЗ 4.0 · программа v9.0.0
Автоматизированная информационная система поддержки принятия решений для работы с предприятиями отрасли телекоммуникаций, вычислительной техники и средств связиЯдро + модули · MicrokernelТЗ 4.0

Вариант А · «Техноконтур-Сеть»

Сетевой вариант: защищённое облако, доступ через Интернет (HTTPS/TLS 1.3), автообмен с внешними системами (ФНС, ГИСП, Роспатент), многоарендность. Модель OPEX.

Вариант Б · «Техноконтур-Контур»

Автономный вариант: локальная сеть без выхода в Интернет (air-gap), отечественные ОС и СУБД, класс защиты не ниже 1Б (ФСТЭК), обновление через носитель с ЭЦП ГОСТ Р 34.10-2012. Модель CAPEX.

При включении: аутентификация JWT (+MFA/TOTP для L7), реестр, паспорта, проекты и шина событий загружаются из СУБД бэкенда; картооснова MOD-GEO — Leaflet + OSM (кнопка «🌐 OSM/Leaflet» на геокарте). Демо-учётки: admin/tc-admin-2026 (L7, MFA) · analyst/tc-analyst-2026 (L5) · sarmat/tc-org-2026 (L4, предприятие E14) · guest/tc-guest-2026 (L0). Без сервера — демо-режим (модельные данные в файле).
Демонстрационный прототип АИС «Техноконтур» (шифр «Провидец»), программа версии 8.0.0 по ТЗ версии 4.0. Реализован архитектурный принцип «Ядро + Модули»: все модули взаимодействуют исключительно через ядро (шина событий, API Gateway, IAM). Данные — модельные. Картографическая основа — условная схема (в промышленной версии: Яндекс.Карты / 2ГИС / OSM, OGC WMS/WFS).
