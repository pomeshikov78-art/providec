Реализовано в бэкенде (проверяется тестами `tests/test_stage5_security.py`):

| Механизм | Реализация | Статус |
|---|---|---|
| Аутентификация | PBKDF2-HMAC-SHA256, 100 000 итераций, соль 16 Б | ✅ |
| Сессии | JWT access (60 мин) + refresh (12 ч), jti, blacklist при logout | ✅ |
| MFA | TOTP (RFC 6238, pyotp) для ролей из `TC_MFA_REQUIRED_ROLES` (по умолчанию L7) | ✅ |
| RBAC | таблицы `iam_policies` (subject_role × action × effect), приоритет deny | ✅ |
| ABAC | условие `org_eq_subject`: L4 — только собственное предприятие | ✅ |
| Защита от перебора | блокировка УЗ на 15 мин после 5 неудачных попыток (HTTP 423 + аудит + событие) | ✅ |

## Вариант Б (air-gap) — особенности
* Внешний IdP и ЕСИА недоступны → только локальная аутентификация (OIDC-маршруты возвращают 501).
* JWT-подпись в production заменяется на ЭП ГОСТ Р 34.10-2012 через СКЗИ (CryptoProvider).
* Хранение секретов: `TC_JWT_SECRET` — из сертифицированного хранилища ключей, не из ENV в открытом виде.

## Чек-лист соответствия профилю ФСТЭК (вариант Б, класс 1Б) — стартовый
1. Идентификация и аутентификация (ИАФ): ✅ реализована; для 1Б — замена на СКЗИ-профиль (⏳).
2. Управление доступом (УПД): RBAC+ABAC, deny-by-default: ✅; испытания в составе ПС: ⏳ (Фаза 5 плана).
3. Ограничение программной среды: контейнеризация, минимальный образ (distroless/ОС «Оникс»/Astra): ⏳ Фаза 5.
4. Защита машинных носителей: шифрование томов СКЗИ: ⏳ Фаза 5.
5. Регистрация событий безопасности (РСБ): WORM-журнал, хеш-цепочка, ≥ 12 мес хранения: ✅ (хранение — настройка БД).
6. Антивирусная защита: на уровне узла (Kaspersky/Dr.Web сертифицированные): ⏳ вне площадки кода.
7. Обнаружение вторжений (СОВ): IDS на периметре контура: ⏳ инфраструктурно.
8. Целостность ПО: ЭП пакетов ядра и модулей (ГОСТ): ⏳ CryptoProvider.
9. Конфиденциальность каналов: TLS 1.3 / СПДС: ✅ конфигурация nginx.
10. Аттестация объекта информатизации: ⏳ после опытной эксплуатации (Фаза 6 плана, км. 31–33).
